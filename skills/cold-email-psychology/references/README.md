# Cold Email Reference Library

The reference files used by the Cold Email Psychology skill. They are plain Markdown, so you can also read them directly.

| File | What it contains |
|---|---|
| [principles.md](principles.md) | Sales psychology principles for cold email, ranked by how often they appear, with how to apply each |
| [frameworks.md](frameworks.md) | The most-used cold email structures (85 of 216) with a quick-pick table; the rest are in archive/frameworks-extra.md |
| [hooks.md](hooks.md) | Cold email opening lines and subject line patterns |
| [ctas.md](ctas.md) | Call to action types for cold email and when each works |
| [examples.md](examples.md) | 53 original cold email examples |
| [followups.md](followups.md) | Cold email follow-up playbook: how many, when, what each touch does |
| [practices.md](practices.md) | Writing, list-building, deliverability and compliance practices |
| [checklist.md](checklist.md) | The grouped pre-send checklist (about 30 items, Quick items marked) with rule resolutions |
